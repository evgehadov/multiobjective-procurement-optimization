# Лабораторная работа № 3

## Многокритериальная эволюционная оптимизация плана закупок расходных материалов

**Дисциплина:** Эволюционное программирование  
**Язык программирования:** Python 3.12 или новее  
**Алгоритм:** NSGA-II  
**Вариант:** 7

## 1. Цель работы

Цель лабораторной работы — разработать программу многокритериальной эволюционной оптимизации плана закупок расходных материалов на месяц, реализовать алгоритм NSGA-II и сравнить его результаты с методом взвешенной суммы.

Программа должна учитывать ограничения бюджета, минимизировать стоимость закупок, взвешенный дефицит материалов и стоимость хранения оставшихся запасов.

## 2. Математическая модель

Для каждого материала \(i\) заданы следующие параметры:

- \(c_i\) — цена единицы материала;
- \(s_i\) — текущий запас;
- \(d_i\) — спрос на материал за месяц;
- \(m_i\) — минимальный желаемый остаток;
- \(w_i\) — вес дефицита;
- \(h_i\) — коэффициент стоимости хранения;
- \(u_i\) — максимальное количество материала, которое можно закупить.

Переменная \(x_i\) обозначает количество закупаемого материала. Генотип представляет собой целочисленный вектор:

\[
x_i \in \{0,1,\ldots,u_i\}.
\]

Требуемое количество закупки определяется по формуле:

\[
r_i=\max(0,d_i+m_i-s_i).
\]

Дефицит после закупки:

\[
\delta_i=\max(0,r_i-x_i).
\]

Остаток материала после удовлетворения месячного спроса:

\[
z_i=\max(0,s_i+x_i-d_i).
\]

В задаче минимизируются три целевые функции.

**1. Стоимость закупки:**

\[
f_1(x)=\sum_i c_i x_i.
\]

**2. Взвешенный дефицит материалов:**

\[
f_2(x)=\sum_i w_i\delta_i.
\]

**3. Стоимость хранения остатков:**

\[
f_3(x)=\sum_i h_i z_i.
\]

Основное ограничение — бюджет закупки:

\[
\sum_i c_i x_i \le B,
\]

где \(B\) — доступный бюджет.

План должен удовлетворять ограничению бюджета. Дефицит материалов является целевой функцией, а не самостоятельным ограничением допустимости: алгоритм может рассматривать планы с неполным покрытием спроса.

## 3. Генерация исходных данных

Исходные данные формируются программно с помощью генератора случайных значений. Для каждого материала задаются цена, текущий запас, месячный спрос, минимальный остаток, вес дефицита, коэффициент хранения и верхняя граница закупки.

Использование фиксированного начального значения генератора случайных чисел позволяет воспроизводить эксперименты.

## 4. Реализация алгоритмов

### 4.1. NSGA-II

Алгоритм NSGA-II реализован самостоятельно, без использования готовых реализаций многокритериального генетического алгоритма.

Реализация включает:

- формирование начальной популяции допустимых решений;
- турнирный отбор родителей;
- скрещивание целочисленных генотипов;
- мутацию решений;
- определение доминирования по Парето;
- сортировку популяции по фронтам недоминируемых решений;
- вычисление расстояния скученности;
- элитистический отбор следующего поколения;
- формирование множества недоминируемых решений.

При сравнении решений учитываются все три целевые функции.

### 4.2. Метод взвешенной суммы

Для сравнения используется метод взвешенной суммы. Целевые функции нормализуются и объединяются в одну скалярную оценку с помощью весовых коэффициентов.

Изменение весов позволяет получать решения с различными компромиссами между стоимостью закупки, дефицитом и хранением.

Результаты метода используются в сравнении с NSGA-II.

## 6. Установка

Для работы необходим Python версии 3.12 или новее.

Создание виртуального окружения:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

Установка зависимостей:

```bash
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

## 7. Запуск программы

Посмотреть доступные параметры запуска:

```bash
python main.py --help
```

Запустить отдельные эксперименты:

```bash
python main.py --experiment A
python main.py --experiment B
python main.py --experiment C
python main.py --experiment D
```

Запустить все эксперименты:

```bash
python main.py --experiment all
```

Также можно задать количество запусков, размер популяции, число поколений, вероятность мутации и папку сохранения результатов.

Пример сокращённого запуска для проверки работоспособности программы:

```bash
python main.py --experiment A --runs 20 --population 8 --generations 1 --output results_smoke
```

Пример запуска эксперимента A с основными параметрами алгоритма:

```bash
python main.py --experiment A --runs 20 --population 100 --generations 200 --seed 20261018 --output results
```

Сокращённый запуск предназначен только для проверки программы. Его результаты не следует использовать вместо результатов полноценных экспериментов.

## 8. План экспериментов

В проекте предусмотрены четыре эксперимента.

**Эксперимент A — серия независимых запусков.**

Алгоритм NSGA-II запускается с разными начальными значениями генератора случайных чисел. Анализируются полученные недоминируемые решения и метрики качества.

**Эксперимент B — влияние размера популяции.**

Сравниваются результаты работы алгоритма при разных размерах популяции.

**Эксперимент C — влияние вероятности мутации.**

Исследуется влияние вероятности мутации на качество получаемых решений.

**Эксперимент D — сравнение алгоритмов.**

Результаты NSGA-II сравниваются с результатами метода взвешенной суммы.

Для окончательного анализа необходимо использовать полноценные запуски с параметрами, соответствующими требованиям лабораторной работы. Предварительные проверки работоспособности не заменяют экспериментальные серии.

## 9. Метрики и визуализация

Для анализа результатов используются:

- трёхмерный гиперобъём множества решений;
- количество недоминируемых решений;
- агрегированные статистические показатели по сериям запусков;
- значения трёх целевых функций;
- проверка соблюдения бюджетного ограничения.

Гиперобъём рассчитывается в нормализованном пространстве целевых функций с фиксированной опорной точкой.

Для визуального анализа строятся три проекции множества решений:

1. Стоимость закупки — взвешенный дефицит.
2. Стоимость закупки — стоимость хранения.
3. Взвешенный дефицит — стоимость хранения.

Эти графики позволяют анализировать компромиссы между критериями.

## 10. Сохранение результатов

Результаты экспериментов сохраняются в указанной папке. Для каждого эксперимента предусмотрены следующие типы файлов:

- `experiment_*_metrics.csv` — метрики качества;
- `experiment_*_solutions.csv` — найденные решения и значения целевых функций;
- `experiment_*_summary.json` — сводная информация об эксперименте;
- PNG-файлы с проекциями множества решений;
- график динамики гиперобъёма, если история его вычисления доступна.

Файлы результатов можно использовать для дальнейшего анализа и подготовки отчёта по лабораторной работе.

## 11. Воспроизводимость и ограничения

Воспроизводимость обеспечивается фиксированными начальными значениями генератора случайных чисел и сохранением параметров экспериментов.

NSGA-II является стохастическим алгоритмом. Поэтому качество найденных решений может различаться между запусками. Сравнение алгоритмов следует проводить по сериям экспериментов и нескольким метрикам, а не по одному удачному результату.

Итоговые выводы должны основываться на результатах полноценных экспериментов, а не только на сокращённых проверочных запусках.
